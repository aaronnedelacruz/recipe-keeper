# Recipe Keeper

A simple Android application built with Kotlin that allows users to create and organize their own recipe collection by storing recipe names, ingredients, and cooking instructions.

> **Note:** *This repository showcases one of my earlier Android projects. While I would approach certain implementation details differently today, I have kept the project unchanged to document my learning progress.*

## Features

* Add a recipe name
* Enter a list of ingredients
* Add cooking instructions
* Compile recipe information into a single view
* Simple and user-friendly interface

## Tech Stack

* Kotlin
* Android Studio
* XML Layouts

## Getting Started

### Prerequisites

* Android Studio
* Android SDK

### Installation

1. Clone the repository.

   ```bash
   git clone https://github.com/your-username/recipe-keeper.git
   ```

2. Open the project in Android Studio.

3. Sync the Gradle files.

4. Build and run the application on an Android emulator or physical device.

## How It Works

1. Enter the recipe name.
2. Add the ingredients for the recipe.
3. Enter the cooking instructions.
4. Submit the information to compile and display the complete recipe.
